# ☁️ Cloud Resume Builder

A full-stack Cloud Resume Builder application built using AWS Cloud services. This project allows users to register, login, create resumes, preview them with multiple templates, and download them as PDF.

---

## 🚀 Features

- User Registration
- User Login
- Dashboard
- Resume Builder
- Resume Preview
- Multiple Resume Templates
- PDF Download
- AWS Lambda Backend
- Amazon API Gateway
- Amazon DynamoDB
- Amazon S3 Static Website Hosting
